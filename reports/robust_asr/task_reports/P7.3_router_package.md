## Limits / risks

- `rp5_inference.py` is stdlib-only; if the RP5 runtime ever imports
  `rp5_inference` indirectly via a package that injects sys.path
  with third-party deps, the test
  `test_rp5_inference_runs_under_stdlib_only_subprocess` will catch
  drift in a clean `python -I` subprocess.
- `deterministic_selector.json` is the runtime source of truth for
  the Section 5.5 constants. Edits to `router_v1.yaml` must be
  republished by re-running `package_deterministic_selector.py` or
  the metadata sha256s will diverge from the on-disk files (caught
  by `test_metadata_file_sha256s_match_on_disk`).
- The `no_speech_prob` / `avg_logprob` proxies in the parquet were
  computed by P6.1 from `normalized_transcript` and a fixed
  `avg_logprob = 0.0` default (the P2.1 eval table does not expose
  these features and P6.2 was `SKIPPED_BY_OUTCOME_E`). The selector
  package and its test vectors document this proxy provenance.
  Counterfactual `assemblyai_available=True` branches are exercised
  in `test_vectors.json` and the runtime test, but **not** in the
  parquet scan, because the parquet was built with
  `assemblyai_available = False`.
- No Slurm submission, no Apptainer GPU, no AssemblyAI call, no
  LoRA call. CPU-only login-node task under CLAUDE.md §7.
