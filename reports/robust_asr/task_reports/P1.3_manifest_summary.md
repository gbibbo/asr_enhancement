## Deliverables

### Scripts (per agent plan §4.3)

- `scripts/robust_asr/build_public_manifests.py`
  sha256 `bd10c89095136cdaa33ca0775ed258daea27a5a896a36f6e7bdf640d3373fed9`
  Reads `configs/robust_asr/data_v1.yaml`. For each LibriSpeech split
  whose subset root resolves on host, walks `<root>/<subset>/<speaker>/<chapter>/*.flac`,
  hashes each file (streaming SHA-256), probes duration with
  `soundfile.info`, and writes one parquet per `<dataset>_<split>` with
  the column set `{audio_id, source_dataset, source_subset, speaker_id,
  chapter_id, utterance_id, audio_path_or_uri, audio_sha256,
  duration_s, sample_rate, num_frames, split_label}`. OOD-real /
  Common-Voice-demo splits are skipped with explicit
  `SKIPPED_OOD_PUBLIC_DEFERRED` notation when the dataset root is
  absent or the speaker list is empty (per §9 P1.3 Decision rule 1).
  Halts (exit 1) only when a required LibriSpeech split has no
  resolvable rows. Multi-threaded I/O (`--workers 16`).
- `scripts/robust_asr/summarize_manifests.py`
  sha256 `3203ec85df54eac6faeb49b10015b3ad85fe6a163031acc7828726d597617a27`
  Reads every parquet under `--manifest-root`, computes per-manifest
  row count, duration sum, distinct speaker count, parquet byte sha256,
  and writes a markdown summary; reports the OOD-real claim status
  (`disabled (BLOCKED_OOD_PUBLIC)` while `data_v1.yaml.ood_real.blocked=true`).
