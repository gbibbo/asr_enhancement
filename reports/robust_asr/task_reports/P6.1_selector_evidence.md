## Implementation

- `libs/common/versions.py`: appended
  `DETERMINISTIC_SELECTOR_VERSION = "deterministic_selector_v1"`.
  `NORMALIZATION_VERSION`, `METRICS_VERSION`, `DEGRADATION_VERSION`,
  `ENHANCER_VERSION` preserved.
- `scripts/robust_asr/build_selector_evidence_table.py`: applies the
  Section 5.5 reference `deterministic_select(no_speech_prob,
  avg_logprob, assemblyai_available, lora_available, …)` to every
  row. `no_speech_prob` proxied from
  `normalized_transcript == ""` (1.0 vs 0.0); `avg_logprob` defaults
  to 0.0 (the escalation branch is unreachable under
  `assemblyai_available=False`). Writes the schema named in the
  validator (`audio_id`, `reference_normalized`,
  `whisper_base_ct2_int8_wer`, `whisper_base_ct2_int8_latency_ms`,
  `selected_action`, `selector_reason`, `ask_repeat_allowed`,
  `assemblyai_available`, `lora_available`) plus
  `whisper_base_ct2_int8_wa`, proxy columns,
  `condition_family`, `degradation_id`, `source_split`,
  `deterministic_selector_version`, `normalization_version`.
- `scripts/robust_asr/validate_selector_evidence.py`: enforces the
  six §982-§1001 assertions. Strips the `::<degradation_id>` suffix
  before checking LoRA-train disjointness so that eval rows under
  `librispeech/dev-clean/...::clean::id` are compared at the same
  granularity as the LoRA-train manifest
  (`librispeech/train-clean-100/...`). Demo manifest is treated as
  the empty set when `artifacts/robust_asr/demo/demo_examples_manifest.json`
  is absent (pre-P8.2).

## Limits / risks

- The `no_speech_prob` proxy from an empty `normalized_transcript`
  is a conservative lower bound for true `no_speech_prob` and only
  fires on hard decode failures. P6.2 would have produced the
  Whisper decode features directly, but P6.2 is
  `SKIPPED_BY_OUTCOME_E`; the deterministic selector therefore
  defaults to `whisper_base_ct2_int8` everywhere it does not detect
  a `no_speech` failure. This is consistent with agent plan
  §1505-§1510 ("If only `whisper_base_ct2_int8` remains,
  `selected_action` is either `whisper_base_ct2_int8` or
  `ask_repeat`.").
- No router learning is performed; no router_features,
  router_train/val/test_locked matrices, router candidates, or
  selected_router package are produced (those belong to
  P6.2 / P7.1 / P7.2 and are out of scope under Outcome E).
- No AssemblyAI call (`BLOCKED_API`); no LoRA call
  (`SKIPPED_BY_DECISION_A`).
